# Phase D1 — Panier serveur — Plan d'implémentation

> **Pour les travailleurs agences :** exécuter task par task, syntaxe checkbox. TDD : test d'abord, le voir échouer, implémenter au minimum, revoir vert, commiter.

**Goal :** panier côté serveur (1 panier actif par utilisateur, lignes quantité bornées au stock, prix toujours relu côté serveur) + page `/panier` Next.js.

**Architecture :** nouvelle app Django `apps/commerce` (panier, puis commandes en D2+). Modèles `Cart` (OneToOne user) et `CartItem` (unique par artwork, quantity CHECK > 0, **aucun prix stocké**). Endpoints session cookies + CSRF existants, réponses plates (pas d'enveloppe succès), erreurs via l'enveloppe `{"error": …}` déjà en place.

**Tech Stack :** Django 6.1 + DRF (session auth `ArtflowSessionAuthentication`), Next 16 / React 19 / Tailwind 4, tokens Clay (`formatXAF` / PriceTag existants).

**Spec :** `docs/api.md` §6 (routes panier), `docs/database.md` §3 (carts/cart_items), `docs/screens.md` `/panier`, `docs/requirements.md` EF-8.2.

## Contraintes globales

- Devise : **XAF entiers** (BigInteger) — jamais de décimales.
- Aucun prix stocké dans le panier — relu à chaque GET/quote/checkout.
- Auth cookies HttpOnly + CSRF double-submit ; appels frontend **sans slash final** (piège 308/301 C4).
- Réponses succès plates ; erreurs enveloppe `{"error": {"code", "message", "details"}}`.
- Anonyme sur routes panier → **401** (jamais 403/500 — piège AllowAny global).
- TDD obligatoire ; gates : `uv run pytest`, `uv run ruff check .`, `uv run python manage.py makemigrations --check` ; frontend `npx oxlint src`, `npx vitest run`, `npm run build`.
- FR partout dans l'UI.

## Review Focus (les pièges qui mordent)

1. **Double POST même œuvre** → incrémenter la ligne existante, pas IntegrityError 500 (unique `(cart, artwork)`).
2. **Stock chuté après ajout** → GET doit flagger `quantity_exceeds_stock` / `artwork_unavailable` sans casser (l'œuvre peut aussi passer HIDDEN).
3. **Cross-user** → PATCH/DELETE ligne d'un autre user = 404 (queryset scopé au panier du request.user).
4. **quantity < 1 ou > stock à l'ajout** → 400 `validation_error` avec details par champ, pas un 500.
5. **`/cart/items/{id}/` avec un autre UUID** → 404, et un id inexistant aussi (pas de distinction).

```python
class Cart(models.Model):
    user = models.OneToOneField(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name="cart")
    updated_at = models.DateTimeField(auto_now=True)
    created_at = models.DateTimeField(auto_now_add=True)

class CartItem(models.Model):
    cart = models.ForeignKey(Cart, on_delete=models.CASCADE, related_name="items")
    artwork = models.ForeignKey("catalogue.Artwork", on_delete=models.CASCADE)
    quantity = models.PositiveIntegerField(validators=[MinValueValidator(1)])
    created_at = models.DateTimeField(auto_now_add=True)
    # Meta : UniqueConstraint (cart, artwork) "uniq_cart_artwork"; CheckConstraint quantity >= 1
```
